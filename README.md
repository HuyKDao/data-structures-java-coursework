# Data Structures Coursework in Java (UC Berkeley CS 61B)

Write-ups of the projects I completed in **CS 61B: Data Structures** at UC Berkeley (Fall 2022). The course covers object-oriented programming in Java, data structures (linked lists, resizing arrays, maps, heaps, graphs), algorithm efficiency and testing.

> **About the code:** CS 61B doesn't allow posting project solutions publicly, so each folder explains what I built and what I learned instead of posting code. I'm happy to walk through the code in an interview.

| # | Project | Focus | Key concepts |
|---|---|---|---|
| 2 | [Deques & Guitar Synthesizer](02-deques-and-guitar-synthesizer/) | Building core data structures | Linked lists, circular resizing arrays, generics, iterators, JUnit |
| 3 | [NGordnet: Word Trends & WordNet](03-ngordnet-word-trends-and-wordnet/) | Data processing and graph search | Hash maps, tree maps, graphs, priority queues |

## Skills and tools
Java, object-oriented design, interfaces and inheritance, generics, linked lists, resizing arrays, hash maps, tree maps, directed graphs, graph traversal, priority queues, time-series data, JUnit testing, IntelliJ.
